# docs

ISMS-P 인증 준비 프로젝트의 문서 디렉터리.

```
docs/
├── sources.md          # 원본 문서 목록 및 메타데이터(버전/출처/다운로드일)
├── sources/            # 원본 소스 문서 (SSOT, 수정 금지)
├── analysis/           # 원본 문서 분석 결과
└── design/             # 기술 점검 설계 문서
```

- `sources/`의 원본 파일은 절대 수정하지 않는다.
- 분석·설계 문서는 원본을 참조하되, 원본에 없는 내용을 임의로 만들지 않는다.
- 자세한 내용은 각 하위 디렉터리의 README를 참고한다.
